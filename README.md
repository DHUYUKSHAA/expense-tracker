# Expense Tracker

A web-based Expense Tracker application developed to help users efficiently manage and monitor their daily expenses through a simple and user-friendly interface.

## Features
- Secure user registration and login
- Add and manage daily expenses
- View expense history
- Delete expense records
- Automatic total expense calculation

## Technologies Used
- Frontend: JSP
- Backend: Java Servlets, JDBC
- Database: PostgreSQL
- Server: Apache Tomcat

## Project Description
The Expense Tracker application allows users to digitally record and track their daily spending activities. The system provides secure authentication for personalized expense management. Users can add, view, and delete expense records, while the application automatically calculates total expenses for effective financial tracking.
