# Expense Tracker

A web-based Expense Tracker application developed to manage daily expenses in a simple and organized way.

## Features
- User registration and login
- Add expenses
- View expenses
- Delete expenses
- Total expense calculation

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java Servlets, JDBC
- Database: PostgreSQL
- Server: Apache Tomcat
